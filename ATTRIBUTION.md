# Data attribution and licensing

The code in this repository and the transit data shipped with it are under
different terms. This file records which is which.

## `data/bmtc.npz` — real Bengaluru bus network

A prebuilt timetable snapshot (see `src/transitlab/gtfs/snapshot.py`) derived
from an unofficial GTFS dataset for BMTC bus services.

| | |
|---|---|
| **Source dataset** | [Vonter/bmtc-gtfs](https://github.com/Vonter/bmtc-gtfs) |
| **Source licence** | Open Database License (ODbL) v1.0 |
| **Transit authority / operator** | Bengaluru Metropolitan Transport Corporation (BMTC) |
| **Feed validity** | 2026-09-07 to 2027-09-07 (`feed_info.txt`) |
| **Built with** | `scripts/make_snapshot.py data/bmtc.zip data/bmtc.npz --walk-radius 250` |

`data/bmtc.npz` is a **derived database** under ODbL §4.4, so it is offered
here under the **same ODbL v1.0 licence** as the dataset it comes from. Anyone
redistributing it, or a further derivative of it, is bound by those terms —
which is not the licence covering the source code in `src/`.

Two things about the snapshot are mine rather than BMTC's, and should not be
mistaken for official data:

- **The walking transfers are invented.** The source feed declares no
  `transfers.txt`, so 20,358 footpaths were generated from straight-line
  distance between stops within 250 m, at an assumed 1.25 m/s with a 1.4
  detour factor. No footway, crossing or flyover was consulted. See
  `src/transitlab/gtfs/footpaths.py` for why this is necessary and what it
  gets wrong.
- **Trips the loader could not use were dropped** — 121 of 57,836, for
  unusable or missing stop times.

### Known limitations of the source data

Stated by the upstream project, and they matter when reading any result:

- It is **unofficial**, assembled from the Namma BMTC app rather than
  published by BMTC as GTFS.
- The app's timetables are **known to be inaccurate**, so arrival times here
  are indicative, not authoritative.
- **Only routes with functioning live tracking are included.** A missing route
  reflects that gap, not a route that does not operate.

Treat journeys from this feed as a demonstration that the router works on
real-world data at real-world scale — not as travel advice.

## `data/sample-feed.zip` — synthetic feed

Generated by `scripts/make_sample_feed.py` from
`src/transitlab/gtfs/synthetic.py`. Entirely invented: no real network, no
real timetable, no licensing constraints. It is what the tests and the
differential benchmark run against, because it is deterministic and small.
